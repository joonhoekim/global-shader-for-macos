# 쓰는 법

*[← README](../README.ko.md)  ·  [English](usage.md)*

## 인스턴스는 언제나 하나

**이미 돌고 있으면 셰이더를 거는 명령은 두 번째를 안 띄우고 돌고 있는 쪽을
바꾼다.** 두 번째 인스턴스는 그 자체가 되먹임이라([구조](architecture.ko.md))
띄울 수가 없고, 그러면 남는 뜻은 "바꿔라" 하나뿐이다. 리눅스에서 셰이더를 갈아
끼우던 스크립트가 컴포지터에게 말을 걸던 자리가 여기서는 이것이다.

끝내는 길은 메뉴 막대의 `◲` → 끝내기, `--stop`, 또는 SIGINT/SIGTERM.

## 체인 — 여러 장을 순서대로

하이프랜드의 `decoration:screen_shader` 는 한 장만 받는다. 그래서 브라운관 뒤에
필름 그레인을 더하고 싶으면 두 셰이더를 손으로 한 파일에 합쳐야 했고, 합치는
순간 그 둘을 따로 끄거나 순서를 바꿔 볼 수가 없다.

**여기서는 합성 순서를 우리가 정하므로 그럴 이유가 없다.**

```sh
global-shader shaders/crt/crt.frag shaders/crt/glow.glsl
```

패스마다 오프스크린에 그리고 다음 패스가 그걸 `tex` 로 받는다. 셰이더 쪽에서
보면 자기가 화면 한 장을 받는다는 사실이 그대로라서, 체인에 넣은 파일이 혼자
걸릴 때와 똑같이 동작하고 리눅스에서도 계속 그대로 돈다. **파일은 여전히 한 글자도
안 고친다.**

중간 타겟은 두 장으로 핑퐁한다. 어느 패스도 두 단계 前 결과를 안 보므로 N 장을
잡을 이유가 없다 — 4K 에서 한 장이 22MB 다.

한 칸이라도 번역에 실패하면 **아무것도 안 바꾼다.** 앞의 것만 걸어 두면 브라운관
뒤에 오던 그레인이 조용히 빠진 화면이 되는데, 그건 안 바뀐 화면보다 알아채기
어렵다.

못 거는 체인은 **설정에도 안 남는다.** 화면을 안 건드리는 것만으로는 모자란다 —
깨진 칸이 `config.json` 에 남으면 다음 실행에는 그 체인을 *처음* 거는 길로
들어가고, 거기서 실패하면 통과 셰이더로 뜬다. 오타 하나가 다음 로그인에 가서야
검은 화면이 되는 셈이라 원인을 잇기가 제일 어렵다.

순서·끄고 켜기·빼기는 메뉴 막대에서 하고, 스크립트에서는 소켓으로 한다.

## 메뉴 막대

`◲` 하나에 다 들어 있다. 체인 순서, 손잡이 슬라이더, 프로필, 셰이더 폴더,
배율·프레임 상한·재그리기, 로그인 시 시작.

별도의 설정 창을 안 만든 이유는 이 앱이 `LSUIElement` 라서다. 창을 띄우려면
accessory 앱을 활성화해야 하고 그러면 쓰던 앱에서 포커스를 빼앗는다. 화면에
유리를 씌우는 도구가 배율 하나 바꾸자고 작업을 끊는 건 앞뒤가 안 맞는다.

### 메뉴가 열리면 오버레이가 비켜 준다

오버레이는 `CGShieldingWindowLevel()` — 2147483628 — 에 있고 메뉴의 드롭다운 창은
101 이다. 그래서 메뉴가 열려 있는 동안만 오버레이를 **레벨 100 으로 내린다.** 일반
창(0) · 떠 있는 창(3) · 모달 패널(8) · 메뉴 막대(24)는 그대로 덮으므로 바뀌는 것은
우리 메뉴 하나뿐이다. 대화상자는 반대로 자기 레벨을 shielding 위로 올린다.

메뉴가 유리를 안 먹는 것은 감수한다. 셰이더가 화면을 알아볼 수 없게 만들어도
여기로 빠져나올 수 있어야 한다는 것이 이 창의 전제라, 제어판만은 또렷한 편이 맞다.
이렇게 하기 전에는 [메뉴가 유리 아래로
깔려](notes/history.ko.md#메뉴가-유리-아래로-깔리던-것) 아예 안 보였다.

## 설정과 프로필

```
~/.config/global-shader/          ($XDG_CONFIG_HOME 를 따른다)
  config.json          지금 체인 · 셰이더 폴더 · 실행 옵션 · 로그인 항목 · 언어
  profiles/<이름>.json  체인 한 벌을 이름 붙여 얼려 둔 것
  shaders/             기본 셰이더 폴더 (하위 폴더까지 훑는다)
```

셰이더 폴더는 **두 단까지** 하위 폴더를 따라간다. 메뉴 안의 메뉴는 두 단만
넘어가도 마우스로 따라가기가 어려워서 거기서 끊는데, 넘치는 단을 못 본 척하지는
않고 그 위 단에 **펼쳐서** 붙인다. 안 그러면 파일이 목록에서 조용히 사라져서,
분명히 넣어 둔 셰이더를 사람이 찾아 헤매게 된다.

프로필은 체인 순서와 **손잡이 값과 실행 옵션까지** 함께 담는다. 무거운 셰이더는
배율을 낮춰 두고 싶고 그 판단은 셰이더마다 다르기 때문이다.

```sh
global-shader --profile <이름>          # 걸기 (돌고 있으면 그쪽이 바뀐다)
global-shader --profiles               # 목록
```

저장은 메뉴에서 (`프로필 → 지금 것을 프로필로 저장…`) 하거나 소켓으로 한다.

### `UserDefaults` 가 아니라 JSON 인 이유

이 앱은 설정을 **선언적으로 관리하는 환경**에서 살 것을 전제로 한다 (Nix
home-manager, chezmoi, dotfiles 저장소 같은 것들). 그런 환경의 공통 사정이
하나 있다 — 설정 파일을 스토어나 저장소에서 심링크로 놓으면 대상이 **읽기
전용**이 되므로, 사람이 손으로 고쳐 가며 쓸 값은 "없을 때만 복사"하는 시드
방식으로 두고 진짜 쓰기 가능한 파일을 남긴다는 것이다. 라이싱 중에 고친 값이
rebuild 로 날아가지 않게 하려는 것이다.

`UserDefaults` 는 그 계층에 못 들어간다. 바이너리 plist 라 diff 가 안 되고,
`cfprefsd` 가 캐시를 들고 있어서 밖에서 쓴 값이 언제 반영되는지가 분명하지 않다.
JSON 한 장이면 설정 관리 도구가 시드할 수도, 사람이 고칠 수도, 커밋할 수도 있다. 그래서
정렬된 pretty JSON 으로 쓴다 — 값 하나 바꾼 diff 가 한 줄이어야 커밋해 두고 쓸
마음이 든다.

설정 파일이 읽기 전용이어도 **죽지 않는다.** 메뉴로 바꾼 값이 이번 실행 동안만
살아 있고, 메뉴가 그 사실을 표시한다.

## 로그인할 때 시작

메뉴의 `설정 → 로그인할 때 시작`. 켜면 `~/Library/LaunchAgents/dev.jh.global-shader.plist`
를 쓰고 `launchctl bootstrap` 한다.

`SMAppService` 가 아닌 이유가 둘이다. 인자를 못 싣고, 앱이 자기 설정에서 등록
상태를 다시 쓴다. 그 종류의 상태를 선언적으로 들고 있으려는 환경에서는 진실이
둘이 되고, 둘이 갈리면 "분명히 껐는데 로그인하면 뜬다"가 된다. LaunchAgent 를
직접 쓰면 설정 관리 도구가 놓는 것과 **같은 물건**이 되므로, 나중에 선언적으로
옮겨도 앱이 하던 일과 어긋나지 않는다.

`open -a` 가 아니라 번들 안 실행 파일을 직접 부른다. `open -a` 는 앱을 띄우고
자기는 곧바로 끝나서 launchd 가 "작업이 끝났다"로 보므로 `RunAtLoad` 와 안 맞는다.

### 선언적으로 옮길 때

`~/Library/LaunchAgents` 에 **우리 것이 아닌데 이 바이너리를 부르는** 에이전트가
있으면 앱은 토글을 잠그고 "다른 데서 관리 중"으로 표시한다. 그걸 못 보고 하나 더
만들면 로그인 때 둘이 뜨려 하고, 두 번째는 인스턴스 잠금에 막혀서 "가끔 안 뜬다"가
된다.

```nix
# nix-darwin 이라면 이런 모양이다.
launchd.user.agents.global-shader = {
  command = "/Applications/GlobalShader.app/Contents/MacOS/global-shader";
  serviceConfig = {
    RunAtLoad = true;
    # KeepAlive 는 켜지 않는다. 메뉴에서 끝낸 것은 끝낸 것으로 둬야 한다 —
    # 화면 전체를 덮는 창이 마음대로 되살아나는 건 무섭다.
    StandardOutPath = "/tmp/global-shader.log";
    StandardErrorPath = "/tmp/global-shader.log";
  };
};
```

걸 셰이더는 인자로 안 준다. `config.json` 이 이미 들고 있어서 에이전트가 셰이더를
바꿀 때마다 갈릴 이유가 없다.

## 제어 소켓

`~/Library/Caches/dev.jh.global-shader.sock`. 한 연결에 한 줄, 답 한 덩이, 닫는다.
같은 바이너리가 클라이언트도 겸한다.

**이 소켓으로 오가는 말은 언어 설정과 무관하게 언제나 영어다** — [다국어](i18n.ko.md) 참고.

| CLI | 소켓 | |
|---|---|---|
| `--get` | `list` | 손잡이 전부 (JSON, 값·범위·눈금·설명) |
| `--set N V` | `set N V` | 하나 바꾼다. 범위 밖은 자른다 |
| `--reset [N]` | `reset [N]` | 파일의 값으로. `2.` 면 그 칸 전부 |
| `--chain` | `chain` | 지금 체인 (JSON) |
| `<파일>…` | `chain set A⇥B` | 체인을 통째로 |
| | `chain add A` | 뒤에 한 칸 |
| | `chain remove N` | N 번째 칸을 뺀다 |
| | `chain toggle N` | N 번째 칸을 끄고 켠다 |
| | `chain move F T` | 순서를 바꾼다 |
| | `chain clear` | 비운다 |
| `--profiles` | `profile list` | 프로필 이름들 |
| `--profile <이름>` | `profile load <이름>` | 프로필을 건다 |
| | `profile save <이름>` | 지금 것을 저장한다 |
| | `profile delete <이름>` | 지운다 |
| `--login [on\|off]` | `login [status\|on\|off]` | 로그인 항목 |
| `--reload` | `reload` | 셰이더를 다시 읽는다 |
| `--status` | `status` | 체인·프로필·손잡이 수·화면 수·재그리기·캡처 정체 시간·스트림 재연결 횟수·fps (JSON) |
| `--stop` | `stop` | 끝낸다 |

경로와 프로필 이름은 공백을 품을 수 있으므로 **줄의 나머지 전체**를 하나로 받는다.
여러 경로를 줄 때만 탭(`⇥`)으로 나눈다 — 같은 바이너리가 클라이언트를 겸하므로
그 규약을 우리가 지킬 수 있고, 셸에서 손으로 부를 때 경로 하나면 따옴표가 필요 없다.

`--no-knobs` 로 띄웠거나 승격이 접힌 셰이더에서 `--set` 을 부르면 성공한 척하지
않고 이유를 돌려준다. 슬라이더가 아무 일도 안 하는 것처럼 보이는 게 제일 나쁜
실패다.

## 옵션

**명령줄 옵션은 이번 실행에만 걸린다. 취향으로 바꿀 자리는 메뉴 막대다.**

규칙은 하나다 — 셰이더(체인·프로필)는 남고, 실행 옵션은 안 남는다.
`global-shader crt.frag` 는 "이제부터 crt 를 건다"는 뜻이라 설정에 적히지만,
`--scale 0.7` 은 지금 한 번 재 보려는 것이지 취향을 바꾸는 게 아니다. 그걸 적어
두면 측정 한 번이 조용히 설정을 오염시킨다.

```
--profile <이름>  저장해 둔 체인 한 벌로.
--fps N          캡처·렌더 상한. 기본은 화면 주사율.
--scale F        0.25~1.0. 프레임이 모자랄 때의 첫 손잡이.
--redraw M       auto(기본) | always | never. auto 는 셰이더가 시간을 읽는지 본다.
--no-hot-reload  파일이 바뀌어도 안 읽는다.
--no-knobs       @범위 #define 의 유니폼 승격을 끈다. 승격은 기본이고 비용은 0 이다.
--space-fix M    스페이스 전환 잔상 대처. off(기본) | freeze | hide.
--no-vsync       수직동기를 끈다. 셰이더의 실제 비용을 재는 용도.
--capturable     오버레이를 스크린샷·녹화에 담는다. 되먹임 방어가 한 겹 줄어든다.
--diag           되먹임 진단. 마커를 찍고 캡처에서 되읽는다.
--exit-after N   N 초 뒤 스스로 끝낸다.
--allow-multiple 인스턴스 잠금을 건너뛴다. 시험용.
--lang L         이번 실행의 언어. 안 주면 설정, 그다음 시스템을 따른다.
--check          번역·파이프라인 생성만. 권한도 창도 없이 돈다. 체인도 받는다.
--dump-msl       --check + 번역된 MSL 출력.
-V, --version    버전. `--status` 의 JSON 에도 들어 있다.
```
